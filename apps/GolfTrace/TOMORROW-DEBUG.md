# แผนทดสอบเครื่องจริงพรุ่งนี้

เอกสารนี้ตั้งใจให้ทดสอบตามลำดับจากง่ายไปยาก ถ้าขั้นใดไม่ผ่าน ให้หยุดตรงนั้นและเก็บข้อมูลตามหัวข้อ “ข้อมูลที่ส่งมาให้ดีบัก” ด้านล่าง ไม่จำเป็นต้องเดาสาเหตุเอง

## ก่อนเริ่ม

- เปิด MacBook Pro และ iPhone 17 Pro Max แล้วให้ทั้งสองเครื่องเปิด Wi‑Fi
- เปิดแอป `GolfTrace` บน Mac ก่อน แล้วค่อยเปิดแอป `กล้องวงสวิง` บน iPhone
- ปลดล็อก iPhone และเปิดแอปกล้องวงสวิงค้างไว้ด้านหน้า ถ้ากดล็อกจอหรือสลับไปแอปอื่น ภาพอาจหยุด ซึ่งเป็นข้อจำกัดปกติของ iOS
- อนุญาตสิทธิ์ “กล้อง” และ “เครือข่ายภายใน” หากระบบถาม
- เลือก `1080p 120 FPS (แนะนำ)` บน iPhone
- จัดกล้องให้เห็นทั้งตัว มือ และไม้ครบในภาพ ใช้แสงสว่างพอและไม่ย้อนแสง
- หากจะทดสอบ MLM2PRO ให้เปิดเครื่องไว้ใกล้ Mac แต่ปิดแอป Rapsodo ก่อน เพื่อไม่ให้โทรศัพท์ถือการเชื่อมต่อ Bluetooth ค้าง
- ใช้ LAN ส่วนตัวที่เชื่อถือได้เท่านั้น เพราะเส้นทาง Bonjour/TCP ปัจจุบันยังไม่มี TLS หรือการยืนยันตัวตนระหว่าง iPhone กับ Mac

> การส่งภาพสด **ไม่ต้องเสียบสาย USB‑C** ภาพเดินทางผ่านเครือข่ายระหว่าง iPhone กับ Mac โดยตรง สายมีประโยชน์เฉพาะชาร์จไฟ ติดตั้งแอปรุ่นพัฒนา และเก็บ log จาก Xcode เท่านั้น

## 0. ตรวจ MLM2PRO (ทำเฉพาะเมื่อมีเครื่องและ credential ที่ได้รับอนุญาต)

1. เปิด MLM2PRO แล้วดูหัวข้อ `Rapsodo MLM2PRO` บน Mac แอปจะค้นหาเอง
2. ครั้งแรกแอปจะแสดงชื่อกับรหัสอุปกรณ์ กด `นี่คือ MLM2PRO ของฉัน` เฉพาะเมื่อแน่ใจว่าเครื่องของคุณเป็นเครื่องที่เปิดอยู่ ขั้นนี้ทำให้แอปไม่ส่ง token ไปหาอุปกรณ์ Bluetooth ที่ไม่รู้จัก
3. หากขึ้นว่ารอสิทธิ์ Third-party ให้เปิด Rapsodo เลือก `Play › Third-party` แล้วยืนยัน จากนั้นออกจากหน้าตีหรือปิด Rapsodo เพื่อปล่อย Bluetooth และรอไฟสถานะของ MLM2PRO คงที่
4. หากแอปขอ Secret ให้เปิด `ตั้งค่าสิทธิ์สำหรับนักพัฒนา` และใส่เฉพาะ Secret สำหรับ Simulator connector ที่ Rapsodo อนุญาต ไม่ใช่รหัสผ่านบัญชี หาก Rapsodo ไม่ได้ให้ Secret นี้ การเชื่อมตรงจะยังยืนยันไม่จบ แต่กล้องและการวิเคราะห์วงสวิงยังใช้งานต่อได้
5. รอข้อความ `MLM2PRO พร้อมรับค่าการตี` แล้วตีหนึ่งลูก ตรวจว่ามี Ball Speed, Club Speed, มุมยิงและสปินขึ้นในกล่องเดียวกัน
6. ทำวงสวิงแล้วเปิดประวัติ ตรวจว่าค่าลูกถูกแนบกับวงที่เวลาใกล้ที่สุด หากวงไม่ถูกตรวจพบ ค่าลูกต้องยังถูกเก็บไว้และไม่หายหลังปิด–เปิดแอป

คำว่า credential คือข้อมูลยืนยันสิทธิ์สำหรับโปรแกรม ไม่ใช่รหัสผ่านผู้ใช้ ส่วน token คือรหัสชั่วคราวที่บริการ Rapsodo ตอบกลับ แอปไม่แสดงหรือเขียนสองค่านี้ลง log

## 1. ตรวจการเชื่อมต่อและ 120 FPS

1. ดูที่ Mac ในกล่อง `การเชื่อมต่อ iPhone 120 FPS` สถานะเริ่มต้นควรเป็นการเปิดรอรับภาพ ไม่ต้องกดเชื่อมต่อ
2. เปิดแอปกล้องวงสวิงบน iPhone และรอประมาณ 5–10 วินาที
3. บน iPhone เปิด `ข้อมูลสำหรับตรวจสอบ`
4. ตรวจ `ใช้งานจริง` และ `ตรวจความเร็วภาพจริง`
5. กลับมาดู `ข้อมูลภาพสด` บน Mac

ผลที่ควรเห็น:

- iPhone แสดงค่าที่ใช้งานจริงเป็น `1920×1080 ที่ 120 FPS`
- FPS ที่กล้องส่งจริงและ FPS ที่ส่งไป Mac ควรนิ่งใกล้ 120 หลังเปิดไว้สักครู่ ค่าประมาณ 115–121 ถือว่าใช้ได้ในการทดสอบรอบแรก
- Mac แสดงความละเอียด `1920×1080` และ FPS รับ/ถอดภาพใกล้ 120
- ตัวเลข `ถอดไม่สำเร็จ` ควรเป็น 0 หรือไม่เพิ่มต่อเนื่อง ช่วงเริ่มเชื่อมต่ออาจมีการข้ามภาพบนจอเล็กน้อยได้
- เห็นภาพสดจาก iPhone บน Mac โดยไม่มีปุ่มเชื่อมต่อซ้ำซ้อน

คำว่า FPS หมายถึงจำนวนภาพต่อหนึ่งวินาที ตัวเลข FPS วิเคราะห์ท่าทางบน Mac ไม่จำเป็นต้องเท่ากับ 120 เพราะ Mac เลือกวิเคราะห์ภาพล่าสุดเพื่อไม่ให้ภาพค้าง จากการทดสอบก่อนหน้าอยู่ราว 70–97 FPS แต่ค่าจริงขึ้นกับภาระของเครื่อง สิ่งสำคัญคือโครงกระดูกขยับตามตัวและไม่ค้างตามหลังหลายวินาที

## 2. ตรวจภาพกลับหัวและปุ่มหมุน

1. ถ้าพื้นอยู่ด้านบนหรือคนกลับหัว ให้กด `หมุนภาพ 180°` บน Mac หนึ่งครั้ง
2. ขยับแขนช้า ๆ แล้วดูว่าโครงกระดูกและเส้นทางมือยังวางตรงกับตัว
3. ทำวงสวิงหนึ่งครั้ง แล้วเปิด `ภาพย้อนหลัง` เพื่อตรวจว่าคลิปย้อนหลังหมุนไปทางเดียวกับภาพสด

ผ่านเมื่อภาพ คน โครงกระดูก และเส้นทางมือหันถูกด้านพร้อมกัน หากกดแล้วผิด ให้กดซ้ำเพื่อกลับค่าเดิม ไม่ต้องหมุนทั้ง iPhone และกดปุ่มพร้อมกัน

## 3. ตรวจจับวงสวิงอัตโนมัติ

1. ยืนให้อยู่ครบทั้งตัวในภาพ
2. เข้าท่าจรดลูกและวางมือนิ่งประมาณครึ่งวินาที
3. รอข้อความ `พร้อมจับวงสวิง`
4. สวิงตามปกติ แล้วค้างท่าจบประมาณครึ่งวินาที

สถานะควรเปลี่ยนตามลำดับ:

`วางมือให้นิ่ง` → `พร้อมจับวงสวิง` → `กำลังบันทึกวงสวิง` → `บันทึกวงสวิงแล้ว`

หลังจบควรเห็น:

- เส้นทางมือของวงล่าสุดเรียบต่อเนื่องขึ้น ไม่สั่นหรือหักมุมทุกเฟรม
- ระยะเวลา จำนวนภาพ และเหตุผลที่จบวง
- ค่าจากภาพ 2 มิติ เช่น ทางมือ ความเร็วมือเทียบกับความยาวลำตัว และการเปลี่ยนแนวลำตัว

ค่าพวกนี้เป็นการประมาณจากตำแหน่งข้อมือและข้อต่อในภาพ ไม่ใช่ความเร็วหัวไม้ ความเร็วลูก สปิน หรือมุมยิงแบบเครื่อง launch monitor

## 4. ตรวจคลิปย้อนหลัง

การทดสอบนี้ต้องใช้ทางส่งตรงจากแอป iPhone เพราะคลิปถูกสร้างจากวิดีโอ H.264 ที่ Mac รับไว้

1. หลังวงจบ รอข้อความ `คลิปวงล่าสุดพร้อมดูย้อนหลังแล้ว`
2. แอปควรเปลี่ยนไปหน้า `ภาพย้อนหลัง` ให้อัตโนมัติ หรือเลือก `ภาพย้อนหลัง` เหนือภาพเอง
3. ทดลองเล่นที่ `0.25×`, `0.5×` และ `1×`
4. ลากแถบเวลาไปช่วงต่าง ๆ
5. กด `ถอย 1 เฟรม` และ `เดิน 1 เฟรม`
6. กด `บันทึกคลิปเป็นไฟล์…` แล้วลองเปิดไฟล์ `.mov` ที่บันทึกไว้

ผ่านเมื่อคลิปเปิดได้ มีภาพตั้งแต่ก่อนเริ่มขยับมือจนถึงท่าจบ ไม่มีภาพดำ ไม่มีช่วงเวลากระโดดย้อน และการดูทีละเฟรมทำงาน คลิปนี้ใช้ H.264 เดิมที่ Mac รับมาโดยไม่บีบอัดซ้ำ

## 5. ตรวจการต่อกลับอัตโนมัติ

ทดสอบสองกรณีแยกกัน:

### กรณี iPhone หยุดชั่วคราว

1. ขณะมีภาพสด กด Home หรือสลับไปแอปอื่นประมาณ 5 วินาที
2. Mac ควรแจ้งว่าภาพหยุดหรือกำลังรอ ไม่ควรค้างโดยแสดงว่าเชื่อมต่อปกติ
3. กลับเข้าแอปกล้องวงสวิงและปลดล็อกจอ
4. รอ 5–15 วินาทีโดยไม่กดปุ่มบน Mac

### กรณีเปิด Mac app ใหม่

1. เปิดแอปกล้องวงสวิงบน iPhone ค้างไว้
2. ปิดแล้วเปิด `GolfTrace` บน Mac ใหม่
3. รอ 5–15 วินาที

ผ่านเมื่อภาพกลับมาเอง ตัวนับ FPS เริ่มใหม่ และแอปพร้อมจับวงถัดไปโดยไม่ต้องถอดสาย รีสตาร์ตเครื่อง หรือกดเชื่อมต่อหลายจุด หากไม่กลับมา ปุ่ม `เปิดรับภาพ 120 FPS อีกครั้ง` บน Mac และ `เชื่อมต่อ Mac อีกครั้ง` บน iPhone เป็นทางกู้มือ

## 6. ตรวจประวัติหลังเปิดแอปใหม่

1. ทำวงสวิงให้จบสองวงติดกันโดยเว้นช่วงให้นิ่งระหว่างวง
2. ปิดแอป Mac ได้ทันทีหลังวงที่สองจบ แอปจะรอสร้างและเก็บคลิปที่อยู่ในคิวก่อนปิดตัวเอง
3. เปิดแอป Mac ใหม่
4. ตรวจว่าทั้งสองวงอยู่ในประวัติและเปิดคลิปของวงที่ตรงกันได้

คลังในเครื่องจำกัดไว้สูงสุดประมาณ 20 วงหรือ 4 GiB โดยระบบจะตัดวงเก่าสุดก่อนเมื่อเกินขีดจำกัด

## วิธีดู log ของ Mac

วิธีที่ง่ายที่สุดคือเปิดโปรเจกต์ใน Xcode กด Run แล้วดูพื้นที่ Console ด้านล่าง หากต้องการไฟล์ที่ส่งต่อได้ ให้ปิดแอป GolfTrace ที่เปิดอยู่ก่อน แล้วเปิด Terminal และใช้คำสั่งนี้:

```sh
# เริ่มจาก root ของ repository
cd apps/GolfTrace
xcodegen generate
xcodebuild -project GolfTrace.xcodeproj -scheme GolfTrace -configuration Debug -derivedDataPath /tmp/GolfTrace-Debug build
/tmp/GolfTrace-Debug/Build/Products/Debug/GolfTrace.app/Contents/MacOS/GolfTrace 2>&1 | tee ~/Desktop/GolfTrace-Mac.log
```

ปล่อย Terminal หน้านี้ค้างไว้ระหว่างทดสอบ เมื่อพบปัญหาให้กลับมาที่ Terminal แล้วกด `Control-C` ไฟล์จะอยู่ที่ Desktop ชื่อ `GolfTrace-Mac.log`

ข้อความสำคัญที่ควรเห็นใน log ของ Mac:

```text
[GolfTrace] High-speed sender connected
[GolfTrace] Direct pipeline receive ... → decode ... fps · 1920×1080
[GolfTrace] วิเคราะห์ท่าทาง ... FPS
[GolfTrace] สถานะภาพความเร็วสูง: ...
```

## วิธีดู log ของ iPhone

การส่งภาพไม่ต้องใช้สาย แต่การเก็บ log ครั้งแรกผ่าน Xcode ใช้สาย USB‑C จะง่ายและเสถียรกว่า

1. ต่อ iPhone กับ Mac และกดเชื่อถือเครื่องหากระบบถาม
2. จาก root ของ repository รัน `open apps/GolfTraceCamera/GolfTraceCamera.xcodeproj`
3. เลือก Scheme `GolfTraceCamera` และเลือก iPhone ที่จะทดสอบเป็นเครื่องปลายทาง
4. กด Run แล้วเปิดพื้นที่ Console ด้านล่างของ Xcode
5. ทำให้เกิดปัญหาซ้ำ จากนั้นคัดลอกข้อความตั้งแต่ก่อนเชื่อมต่อจนถึงหลังเกิดปัญหาประมาณ 10 วินาที

ข้อความสำคัญที่ควรเห็นใน log ของ iPhone:

```text
[GolfTraceCamera] H.264 ready 1920×1080 @ 120 fps
[GolfTraceCamera] Direct pipeline capture ... → encode ... → send ... fps
```

ถ้าไม่ต้องการเปิด Xcode ให้ใช้แอป `Console` บน Mac เลือก iPhone ในแถบ `Devices` กดเริ่มรับข้อความ แล้วค้นคำว่า `GolfTraceCamera` วิธีนี้อาจต้องเสียบสายหรือเคยเปิดการเชื่อมต่อเพื่อพัฒนาแบบไร้สายไว้ก่อน

## ข้อมูลที่ส่งมาให้ดีบัก

ส่งชุดเดียวต่อหนึ่งปัญหา โดยมีอย่างน้อย:

1. เวลาที่เกิดปัญหาโดยประมาณ เช่น `10:32 น.`
2. สิ่งที่ทำก่อนเกิดปัญหา 1–3 ขั้น เช่น `สลับไปหน้า Home แล้วกลับมา`
3. ภาพหน้าจอ Mac เต็มหน้าต่าง โดยให้เห็นสถานะเชื่อมต่อ FPS และข้อความวงสวิง
4. ภาพหน้าจอ iPhone หลังเปิด `ข้อมูลสำหรับตรวจสอบ`
5. ไฟล์ `GolfTrace-Mac.log`
6. ข้อความ Console ของ iPhone ตั้งแต่ก่อนเกิดปัญหาจนถึงหลังเกิดปัญหา
7. ระบุว่าสาย USB‑C เสียบอยู่หรือไม่ และทั้งสองเครื่องใช้ Wi‑Fi เดียวกันหรือไม่

อย่าตัด log ให้เหลือเฉพาะบรรทัด error เพราะตัวเลข FPS และสถานะก่อนหน้าเป็นข้อมูลที่ช่วยหาต้นเหตุได้มากที่สุด
