## หลักการ

- ทดสอบทีละชั้นและหยุดที่จุดแรกที่ไม่ผ่าน
- บันทึกค่าตัวเลขจริง ไม่สรุปจากคำว่า “ลื่น” หรือ “ช้า” เพียงอย่างเดียว
- ห้ามตีลูกจริงในบ้านหากไม่มีตาข่าย ระยะ และพื้นที่เหวี่ยงไม้ที่ปลอดภัย
- ค่าจากกล้อง, Rapsodo และ AI ต้องคงแหล่งที่มาแยกกัน

## ปัญหาที่พบ

### BUG-01 — Mac app หายหลังรับภาพ

- รุ่นที่พบ: 1.0 (5)
- ผลภาพก่อน crash: receive/decode 120.0 FPS, 1920×1080, decode failure 0
- ข้อความสุดท้าย: `failed to demangle superclass of VideoPlayerView ... AVPlayerView`
- crash report: `GolfTrace-2026-07-19-110018.ips`
- สาเหตุ: SwiftUI `VideoPlayer` เรียก private `_AVKit_SwiftUI.VideoPlayerView` แล้ว runtime abort บน macOS 26.5.2
- แนวแก้: ใช้ `AVPlayerLayer` โดยตรงและเพิ่ม regression test
- สถานะ: ผ่านการยืนยันด้วยฮาร์ดแวร์ใน build 6; สร้างและเล่นย้อนหลังจริงได้ แอปไม่ล้มและไม่มี crash report ใหม่

### BUG-02 — แอป iPhone ค้างแนวตั้ง

- รุ่นที่พบ: 1.0 (4) บน iPhone 17 Pro Max
- ผู้ใช้ยืนยัน: หมุนเครื่องแล้วหน้ากล้องยังอยู่แนวตั้ง
- หลักฐานระบบ: iPhone รายงาน `currentDeviceOrientationLocked = false`
- หลักฐาน build: `UISupportedInterfaceOrientations` มีทั้ง portrait และ landscape ซ้าย/ขวา
- ผลกระทบ: ตั้งกล้องถ่ายวงแนวนอนไม่สะดวก และ UI ใช้พื้นที่ภาพไม่เหมาะกับงานวิเคราะห์วง
- แนวแก้ build 5: ฟังทิศที่ถือเครื่องแล้วขอหมุน `UIWindowScene`; หมุนเฉพาะ preview layer เพื่อไม่แตะ pixel buffer 120 FPS; layout แนวนอนใช้เมนู 4 คอลัมน์
- สถานะ: build 7 ติดตั้งและเปิดบนเครื่องจริงแล้ว รอผู้ใช้ยืนยันว่าหมุน portrait/landscape ได้ทั้งสองทาง

### BUG-03 — เงานักกอล์ฟดูเหมือนคอขาด

- รุ่นที่พบ: 1.0 (4)
- หลักฐาน: ภาพผู้ใช้ `codex-clipboard-fc29c07d-3e7c-43c2-b7e7-780df105317b.png`
- สาเหตุ: ใช้ SF Symbol `figure.golf` ซึ่งเว้นหัวออกจากลำตัวมากเมื่อขยาย
- ผล build 5: เวกเตอร์วาดด้วยโค้ดยังดูเป็นคนก้างและไม่ผ่าน visual UAT ตามภาพ `codex-clipboard-1229b32f-3a90-4948-af0e-dbe5da3cd772.png`
- แนวแก้ build 7: เลิกใช้ Canvas รูปคนทั้งหมด ใช้ภาพคนจริงสัดส่วนมนุษย์จาก ImageGen พื้นหลังโปร่งใส แยก `ด้านหน้า` และ `หลังแนวตี` พร้อมไม้จริง และลดความทึบเมื่อวางบนภาพกล้อง
- ไฟล์: `GolfTraceCamera/Sources/Resources/GolferFaceOn.png` และ `GolferDownTheLine.png`
- สถานะ: build 7 ติดตั้งและเปิดบนเครื่องจริงแล้ว รอผู้ใช้ตรวจภาพสองมุมด้วยตา

### UI-01 — ภาษาภาพของ iPhone และ Mac ไม่เป็นชุดเดียวกัน

- แนวแก้ build 7: ใช้ ImageGen ออกแบบไอคอนชุดเดียวกันสำหรับหัวไม้ มุมกล้อง เส้นช่วยดู และ AI โปร โดยใช้เส้นขาวกับจุด tracer สีน้ำเงิน
- iPhone: แทนไอคอนสี่ตัวที่ใช้บ่อยในแผงตั้งค่าด่วน
- Mac: ลดแถบด้านบนเหลือ iPhone/สถานะวง/Rapsodo/AI และย้ายหัวไม้ มุมกล้อง เส้นช่วยดูมาเป็นแถบสรุปใต้ภาพสด; การตั้งค่าทั้งหมดอยู่ปุ่มเดียว
- ต้นแบบ: `Design/ImageGen/iPhone-Capture-UX-v1.png` และ `Design/ImageGen/Mac-Main-UX-v1.png`
- สถานะ: build และเปิด Mac จริงผ่าน; รอ visual UAT บน iPhone และการใช้งานระหว่างซ้อม
